# Expo Mobile Starter

This directory is reserved for the production Expo starter template.

Expected baseline:
- Expo + TypeScript
- Expo Router
- API client layer
- auth/session layer
- secure storage abstraction
- query/cache layer
- design-system primitives
- error/loading/empty states
- deep-link support
- notifications integration points
- EAS build profiles
- test setup
- crash reporting integration point

The concrete starter code will be generated in a later template-focused release.
