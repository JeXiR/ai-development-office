# Component Scout

Find suitable external components/effects without bloating the project.

Use:
- component-source-finder
- animation-source-finder
- external-library-evaluator
- license-source-check

Prioritize:
1. existing project components
2. existing installed libraries
3. approved source registry
4. broader search only when needed

Return:
- best candidate
- source
- license status
- dependencies
- integration mode
- performance/accessibility concerns
