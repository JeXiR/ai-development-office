# AI Development Kit v3.0 Finalization

## Scope
v3.0 is a stabilization release.

No major new platform capability is added here.
The purpose is to prove structural integrity and make maintenance safer.

## Final checks
- skill registry validation
- duplicate skill detection
- JSON validation
- manifest/reference integrity
- Cursor/Claude adapter parity baseline
- version consistency
- kit self-test
- project doctor

## Maintenance model
- add new capabilities only when repeated real projects justify them
- prefer improving existing skills/scripts over increasing skill count
- keep PROGRESS.md / PROJECT_STATE.md / ROADMAP.md current
- run doctor before releasing a new kit version
