## Default philosophy

Application UI should be boring in a good way:
stable, accessible, coherent.

Marketing/hero areas can use stronger animation and visual sources.

Do not import marketing-effect patterns into critical forms, accounting screens,
tables, authentication, settings or admin workflows unless there is a clear UX reason.
