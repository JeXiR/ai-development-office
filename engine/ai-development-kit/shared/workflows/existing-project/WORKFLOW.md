# Existing Project Workflow

1. Do not refactor immediately.
2. Inventory frameworks, versions, package managers and runtime.
3. Read docs/README/ADRs.
4. Identify critical entry points and business modules.
5. Run existing tests/build if possible.
6. Note technical debt separately from requested work.
7. Match existing conventions unless they are the direct source of the problem.
8. Add documentation before large architectural modernization.
