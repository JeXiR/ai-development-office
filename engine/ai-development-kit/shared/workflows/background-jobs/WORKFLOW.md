# Background Jobs Reliability Workflow

1. Identify async operation and business invariant.
2. Define stable job payload identifiers.
3. Define idempotency strategy.
4. Define concurrency/uniqueness.
5. Classify transient vs permanent errors.
6. Define retries/backoff/timeouts.
7. Preserve tenant context.
8. Define failure/dead-letter recovery.
9. Add queue/job observability.
10. Add reliability tests.
11. Document operator recovery.
