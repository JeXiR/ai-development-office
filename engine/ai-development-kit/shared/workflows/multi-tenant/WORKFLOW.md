# Multi-Tenant Feature Workflow

1. Identify tenancy strategy.
2. Resolve active tenant centrally.
3. Define membership/authorization.
4. Scope database access.
5. Scope cache.
6. propagate tenant context to queues/jobs.
7. namespace storage.
8. review exports/search/notifications.
9. add tenant-aware observability.
10. add cross-tenant negative tests.
11. run security audit.
