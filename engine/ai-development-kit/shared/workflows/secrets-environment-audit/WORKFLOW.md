# Secrets & Environment Audit

1. Inventory environment variable names.
2. Classify public/private/secret.
3. Compare code references to `.env.example`.
4. Compare Docker/CI/cloud mappings.
5. Scan for likely hard-coded secrets.
6. Check client exposure.
7. Produce remediation without exposing values.
8. Update environment documentation.
9. Map production secrets to secret store where applicable.
