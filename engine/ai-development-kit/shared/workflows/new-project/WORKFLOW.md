# New Project Workflow

1. Choose stack and starter template.
2. Create `docs/PROJECT_STATE.md`.
3. Record architecture assumptions.
4. Configure Cursor + Claude adapters.
5. Establish formatting/lint/testing.
6. Establish environment/config/secrets pattern.
7. Add Docker Compose for local services when useful.
8. Keep storage, queue, mail and database behind framework/application contracts.
9. Define deployment target separately from application code.
10. Commit a clean baseline before feature work.
