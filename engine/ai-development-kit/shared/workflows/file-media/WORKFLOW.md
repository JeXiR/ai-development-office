# File & Media Pipeline Workflow

1. Identify file class and ownership.
2. Decide private/public policy.
3. Define metadata model.
4. Define tenant-aware object key.
5. Validate type/size.
6. Upload to safe storage.
7. Process/scan asynchronously if needed.
8. Generate variants.
9. Persist status/checksum/metadata.
10. Authorize access.
11. Generate signed/public URL.
12. Define lifecycle/retention.
13. Add observability.
14. Add cleanup/recovery.
15. Add security and tenant tests.
