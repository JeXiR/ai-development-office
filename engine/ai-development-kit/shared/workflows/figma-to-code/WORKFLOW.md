# Figma to Code Workflow

1. Read `docs/PROJECT_STATE.md`.
2. Inspect existing design system and related screens.
3. Read the referenced Figma source.
4. Build a mapping:
   - Figma component -> code component
   - Figma variable -> project token
   - Figma asset -> repository asset
5. Identify gaps.
6. Ask only material unresolved questions.
7. Implement smallest reusable set of missing primitives.
8. Build page/feature.
9. Run visual QA against source.
10. Check mobile/tablet behavior.
11. Check accessibility.
12. Check performance/client bundle impact.
13. Record new design-system decisions if introduced.
