# External Source Routing Workflow

1. Run `find-skill`.
2. Determine if external source use is justified.
3. Run `source-router`.
4. Select source category.
5. Check project `docs/frontend/EXTERNAL_SOURCES.md`.
6. Evaluate top candidate(s).
7. Run license/source check.
8. Choose integration mode.
9. Run `source-composer`.
10. Normalize to project design system.
11. QA visual/responsive/accessibility/performance.
12. Register materially reused sources under docs/references.
