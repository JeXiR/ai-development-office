# Frontend Quality Gates Workflow

1. Detect frontend stack and routes.
2. Load performance budgets.
3. Run build/bundle analysis.
4. Run accessibility automation.
5. Run keyboard/reduced-motion review for critical flows.
6. Run visual regression screenshots.
7. Compare against approved baselines.
8. Report performance/a11y/visual regressions separately.
9. Block only agreed severity/budget thresholds.
10. Update PROGRESS.md with unresolved regressions.
