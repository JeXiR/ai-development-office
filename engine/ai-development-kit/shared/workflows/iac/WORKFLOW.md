# Infrastructure as Code Workflow

1. Identify environment.
2. Read infrastructure docs and project profile.
3. Select Terraform/OpenTofu modules.
4. Resolve secrets externally.
5. Run fmt/validate.
6. Generate plan.
7. Run IaC safety review.
8. Review migration/deployment implications.
9. Apply only with explicit intent.
10. Verify health/observability.
11. Update PROGRESS.md and infrastructure docs.
