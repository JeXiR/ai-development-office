# Mobile Feature Workflow

1. Read `docs/PROJECT_STATE.md` and mobile docs.
2. Identify feature entry points and navigation destinations.
3. Determine API contract and auth requirements.
4. Determine persistence/offline needs.
5. Determine required permissions/device APIs.
6. Inspect design/Figma/reference.
7. Reuse existing mobile components.
8. Implement feature.
9. Handle loading/error/empty/offline states.
10. Test deep-link/navigation lifecycle if relevant.
11. Test background/resume/relaunch.
12. Run iOS + Android QA.
13. Update docs when navigation, permissions, storage or release behavior changes.
