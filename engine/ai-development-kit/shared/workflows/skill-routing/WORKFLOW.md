# Skill Routing Workflow

1. Run project-context analysis.
2. Read architecture/docs relevant to the task.
3. Detect stack from repository evidence.
4. Detect task intent.
5. Detect references (Figma/template/screenshot/legacy).
6. Select minimum sufficient skills.
7. Add safety/review skills based on risk.
8. Ignore unrelated technologies even if they exist in the project.
9. Execute task.
10. Re-evaluate skill selection if task scope materially changes.
