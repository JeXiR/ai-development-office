# API Contract Workflow

1. Identify API boundary and consumers.
2. Locate or create OpenAPI contract.
3. Normalize auth/errors/pagination.
4. Validate contract syntax.
5. Generate/update typed clients where justified.
6. Compare against previous contract.
7. Block unreviewed breaking changes.
8. Test backend behavior against contract.
9. Compile/typecheck consumers.
10. document version/deprecation decisions.
