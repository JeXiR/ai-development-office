# Release Workflow

1. Read PROGRESS.md/current task.
2. Inspect repository status and intended release scope.
3. Run project validation gates.
4. Review migrations and API changes.
5. Review Docker/IaC/runtime changes.
6. Check configuration/env requirements.
7. Sync documentation.
8. Generate release notes.
9. Define deployment checklist.
10. Define rollback plan.
11. Mark release READY / BLOCKED.
12. After deployment, run post-release verification.
13. Update PROGRESS.md and PROJECT_STATE.md.
