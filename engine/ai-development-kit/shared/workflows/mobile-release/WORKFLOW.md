# Mobile Release Workflow

1. Freeze target release scope.
2. Run automated tests.
3. Build preview/release candidate.
4. QA representative iOS and Android devices.
5. Verify API/environment config.
6. Verify signing and bundle IDs.
7. Verify crash reporting symbols/source maps.
8. Verify store privacy/permission declarations.
9. Prepare release notes.
10. Submit/stage rollout.
11. Monitor crashes/errors after release.
12. Document hotfix/rollback if needed.
