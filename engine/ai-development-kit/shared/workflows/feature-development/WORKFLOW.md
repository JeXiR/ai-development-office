# Feature Development Workflow

1. Read project state and relevant docs.
2. Locate similar existing functionality.
3. Identify affected frontend/backend/database/infrastructure areas.
4. Confirm requirements that cannot be inferred.
5. Write a small implementation plan.
6. Implement in vertical slices where practical.
7. Add validation/authorization.
8. Add tests.
9. Run relevant lint/type/build/tests.
10. Review security and performance.
11. Update docs/ADR/project state when the feature changes architecture or product behavior.
