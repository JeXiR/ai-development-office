# Test Strategy Workflow

1. Read project profile and architecture docs.
2. Detect current testing frameworks.
3. Inventory critical features.
4. Inventory existing tests.
5. Score feature risk.
6. Map each risk to the cheapest effective test level.
7. Identify missing negative/security paths.
8. Generate `docs/testing/TEST_STRATEGY.md`.
9. Generate `docs/testing/TEST_GAPS.md`.
10. Optionally scaffold missing baseline tests.
11. Re-run after major architecture changes.
