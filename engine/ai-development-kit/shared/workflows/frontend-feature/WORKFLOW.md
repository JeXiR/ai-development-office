# Frontend Feature Workflow

1. Understand task.
2. Read relevant docs and project state.
3. Search for similar screens/components.
4. Inspect design source:
   - Figma
   - screenshot
   - template
   - existing page
   - textual requirement
5. Infer design decisions already answered by the project.
6. Ask only material unresolved questions.
7. Define component/layout plan.
8. Implement using existing design system.
9. Add interaction states.
10. Validate responsive behavior.
11. Validate accessibility.
12. Validate visual fidelity.
13. Validate performance.
