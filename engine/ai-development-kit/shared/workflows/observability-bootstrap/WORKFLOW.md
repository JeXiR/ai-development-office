# Observability Bootstrap Workflow

1. Read project architecture and deployment target.
2. Identify current logging/error tooling.
3. Define service/environment/release identity.
4. Add structured logging.
5. Add exception/error monitoring.
6. Add health/readiness checks.
7. Add queue/job visibility if applicable.
8. Add tracing/metrics when justified.
9. Define alerts and owners.
10. Validate no sensitive data is captured.
11. Document operational runbook.
