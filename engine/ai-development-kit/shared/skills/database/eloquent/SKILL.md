# Eloquent

- Define relationships explicitly.
- Eager load when iterating related data.
- Select only needed fields on expensive/high-volume queries.
- Use local scopes for reusable query semantics.
- Use casts/value objects for meaningful type conversion.
- Protect mass assignment according to project convention.
- Avoid model events for critical invisible business workflows when explicit orchestration is clearer.
- Inspect generated SQL/query count for performance-sensitive code.
