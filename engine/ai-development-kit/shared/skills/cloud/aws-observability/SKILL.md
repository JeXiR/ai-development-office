# AWS Observability
Monitor user-impacting signals:
- request errors/latency
- queue backlog/failures
- DB saturation/slow queries
- container restarts
- CPU/memory/storage pressure
- scheduled job failures

Alerts should be actionable and routed to an owner.
Do not log secrets or sensitive payloads unnecessarily.
