# Mobile Observability

Track:
- crash-free users/sessions
- startup time
- API failure/latency
- ANR/freeze/jank signals where available
- release adoption
- push delivery/open issues
- auth refresh failures
- offline sync failures

Segment by app version and platform to identify regressions quickly.
