# Mobile UI

Check:
- safe areas
- keyboard avoidance
- notches/status/navigation bars
- touch target sizes
- text scaling
- orientation assumptions
- small/large phones
- tablets when supported
- loading/empty/error/offline states
- bottom sheets/modals
- scroll behavior
- platform conventions

Do not merely scale a desktop UI down.
Primary actions must remain reachable and obvious.
