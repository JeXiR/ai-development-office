# Mobile QA

Test:
- fresh install
- upgrade from previous version
- login/logout/account switch
- background -> foreground
- process kill/relaunch
- offline/slow network
- permission allow/deny/permanent deny
- push notification open
- deep link cold/warm start
- keyboard/forms
- small and large screens
- iOS + Android
- dark mode if supported
- accessibility text scaling

Report reproducible failures with device/platform/build context.
