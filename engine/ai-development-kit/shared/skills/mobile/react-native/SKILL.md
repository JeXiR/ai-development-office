# React Native

## First inspect
- React Native version
- Expo managed/bare workflow status
- navigation library
- state/query libraries
- native modules already installed
- iOS/Android-specific code
- styling system

## Principles
- Keep platform-specific code isolated.
- Prefer shared components where behavior is truly shared.
- Avoid unnecessary native dependencies.
- Keep large lists virtualized.
- Do not perform heavy synchronous work on the JS thread.
- Treat permissions, storage and device APIs as infrastructure boundaries.
- Preserve accessibility labels, roles and touch target sizes.
