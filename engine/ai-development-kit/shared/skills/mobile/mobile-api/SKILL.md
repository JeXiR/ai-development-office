# Mobile API

- Centralize base URL, headers and auth behavior.
- Keep environment selection explicit.
- Validate/normalize external data at trust boundaries.
- Cancel obsolete requests where supported.
- Retry only safe/retryable failures.
- Prevent duplicate mutation execution.
- Handle token refresh centrally.
- Distinguish offline, timeout, validation, auth and server errors.
- Keep API client independent from screen components.
