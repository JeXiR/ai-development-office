# Permissions

Only request permissions needed for the current feature.
Request them at the moment value is clear.

For each permission define:
- why needed
- when requested
- denied behavior
- permanently denied/settings flow
- platform differences
- data retention implications

The app must remain understandable when optional permissions are denied.
