# App Store / Play Store Release

Before submission:
- production build tested
- crash-free critical flows
- privacy policy/data declarations accurate
- permission descriptions accurate
- screenshots/metadata current
- login/reviewer access prepared when required
- support/contact links valid
- account deletion requirements handled when applicable
- staged/phased rollout considered

Store approval is a product/compliance workflow, not just a build command.
