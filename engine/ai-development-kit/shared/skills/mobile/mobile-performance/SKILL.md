# Mobile Performance

Prioritize:
1. startup time
2. dropped frames/jank
3. large list rendering
4. image size/caching
5. unnecessary rerenders
6. heavy JS thread work
7. network waterfalls
8. excessive bridge/native module traffic

Use profiling/evidence before adding memoization or architectural complexity.
