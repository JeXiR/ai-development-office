# Gestures

Use gestures for:
- direct manipulation
- swipe actions
- drag/reorder
- sheets
- zoom/pan when domain requires it

Do not hide essential actions behind gestures only.
Provide non-gesture alternatives for important operations.
Resolve conflicts with system back/navigation gestures.
