# Queue Observability

Track:
- queued count
- oldest job age
- processing latency
- retries
- failures
- timeout count
- worker availability
- dead/failed jobs

Alert on user-impacting backlog, not every transient retry.
Tag jobs by type/queue/environment/release where useful.
