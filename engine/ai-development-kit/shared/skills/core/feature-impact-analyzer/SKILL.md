# Feature Impact Analyzer

Inspect for impact on:
- schema/data
- APIs
- permissions
- tenancy
- cache
- queues
- storage
- external integrations
- frontend/mobile
- analytics/observability
- CI/deploy
- docs

Flag hidden coupling and migration risk early.
