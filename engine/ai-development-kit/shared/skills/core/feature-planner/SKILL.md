# Feature Planner

Create a plan covering only affected layers.

Possible sections:
- business behavior
- data model
- backend/service logic
- API
- frontend/mobile
- auth/authorization
- queues/jobs
- files/storage
- external integrations
- observability
- tests
- migration/deployment
- docs

For each section identify:
- change
- risk
- dependency
- test/validation

Avoid ceremony for trivial features.
