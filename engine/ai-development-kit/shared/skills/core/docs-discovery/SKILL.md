# Docs Discovery

Classify documents into:
- product
- roadmap
- requirements
- architecture
- features
- decisions
- operations
- status
- references

Detect:
- duplicates
- contradictions
- obsolete files
- placeholders
- orphan docs
- broken references
- multiple competing sources of truth

Never delete or move user-authored docs blindly.
Safe normalization should preserve history and links.
