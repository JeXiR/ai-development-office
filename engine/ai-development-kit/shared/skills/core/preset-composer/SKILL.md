# Preset Composer

A preset composition is an architecture contract.

Validate:
- package manager compatibility
- monorepo layout
- frontend/mobile/backend integration
- shared package boundaries
- database/cache dependencies
- worker model
- Docker topology
- CI assumptions
- environment contracts

Reject conflicting combinations.
