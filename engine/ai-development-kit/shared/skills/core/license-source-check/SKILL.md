# License & Source Check

Before copying/adapting external code, establish:

- source URL/repository/vendor
- license name
- whether source is free or paid
- commercial-use permission
- modification permission
- redistribution restrictions
- attribution requirements
- developer/team/project limits
- whether generated/exported code has separate terms

## Rules

- Never assume "view source" means reusable.
- Never assume GitHub means open source.
- Never bypass paid access or license controls.
- For purchased libraries, use only within the user's valid license scope.
- Record material license constraints in `docs/references/`.

When license terms are unclear, treat code reuse as blocked and use the source only as visual inspiration until clarified.
