# Git

- Never discard uncommitted work without explicit instruction.
- Inspect status before destructive operations.
- Keep commits focused.
- Do not mix generated files with unrelated code changes unless required.
- Avoid rewriting shared history.
- Prefer descriptive branch and commit naming.
- Before merge/PR, run relevant tests, lint, type checks and build validation.
