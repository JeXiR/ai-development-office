# Project Bootstrap

Modes:

## Existing project
1. run project-analyzer
2. create architecture profile
3. detect relevant skill families
4. install Cursor/Claude adapters
5. preserve existing project docs
6. generate missing AI docs only
7. validate

## New project
1. determine project type
2. determine stack
3. determine deployment target
4. determine optional design/mobile/cloud capabilities
5. create architecture docs
6. install selected adapters/skills
7. validate baseline

Do not install every skill into active project context when selective installation is available.
