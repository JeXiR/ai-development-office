# PHP

- Use strict and meaningful types where supported.
- Prefer constructor/property typing over docblock-only typing.
- Use enums/value objects when they clarify a real domain contract.
- Keep exceptions intentional and actionable.
- Avoid dynamic properties and hidden mutation.
- Follow PSR conventions already adopted by the project.
- Do not add framework-independent abstractions that merely wrap framework APIs without value.
