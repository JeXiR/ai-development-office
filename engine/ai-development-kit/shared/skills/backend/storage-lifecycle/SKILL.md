# Storage Lifecycle

Classify:
- permanent business documents
- user media
- temporary uploads
- exports
- backups
- generated derivatives

For each define:
- retention
- delete eligibility
- archive policy
- legal/business constraints
- cleanup owner

Do not delete business records merely because associated UI data was removed without verifying retention rules.
