# Laravel API

- Validate with Form Requests or equivalent centralized validators.
- Authorize server-side before accessing protected resources.
- Use API Resources/Collections for stable response shape.
- Use proper HTTP status codes.
- Paginate collections that can grow.
- Avoid exposing internal exception details.
- Keep error responses consistent.
- Make mutating retryable endpoints idempotent when duplicate execution is dangerous.
- Document breaking contract changes.
- Consider explicit versioning only when contract evolution requires it.
