# Visual QA

## Compare
- page structure
- alignment
- grid/gaps
- typography size/weight/line-height
- spacing
- radius/borders
- shadows
- icon size/alignment
- component density
- image crop/aspect
- hover/focus/active/disabled states
- loading/empty/error/success states
- responsive transformations
- overflow and clipping

## Priority
1. broken layout/functionality
2. incorrect hierarchy
3. wrong component/state
4. spacing/alignment
5. typography
6. decorative differences

## Rule
Do not compensate for structural mistakes with arbitrary pixel offsets.
Fix the layout model first.
