# Blade

- Escape untrusted output by default.
- Use Blade components for repeated UI structures with meaningful ownership.
- Keep business queries out of templates.
- Prefer server-rendered HTML when JavaScript is unnecessary.
- Use Alpine/Stimulus/vanilla JS selectively for lightweight interaction when that matches the project.
- Reuse project design tokens/classes.
- Preserve validation errors, old input, accessibility and keyboard behavior in forms.
