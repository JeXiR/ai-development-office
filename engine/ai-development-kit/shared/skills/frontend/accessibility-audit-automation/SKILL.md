# Accessibility Audit Automation

Automate:
- semantic violations
- label/name issues
- contrast where tooling can detect
- ARIA misuse
- landmark issues
- obvious focus problems

Manual checks still required for:
- keyboard flow
- focus order
- dialog focus trapping
- screen reader usability
- dynamic announcements
- motion/reduced-motion behavior
