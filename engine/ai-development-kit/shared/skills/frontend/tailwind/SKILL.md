# Tailwind

- Reuse project spacing, radius, typography and color tokens.
- Do not invent arbitrary values when an existing token fits.
- Extract repeated semantic UI into components rather than giant copied class strings.
- Keep responsive behavior intentional.
- Avoid conflicting utility chains.
- Respect dark mode strategy already used by the project.
