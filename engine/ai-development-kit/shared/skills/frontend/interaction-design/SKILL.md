# Interaction Design

For interactive components define:
- trigger
- state transition
- feedback
- cancellation/dismissal
- keyboard behavior
- loading state
- error state
- disabled state
- mobile/touch behavior

Animations must reinforce state changes, not obscure them.
Dangerous actions require clear confirmation or recoverability based on impact.
