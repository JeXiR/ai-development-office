# React

- Keep state as local as practical.
- Derive state instead of duplicating it.
- Avoid effects for pure derivation.
- Use effects for synchronization with external systems.
- Keep components cohesive.
- Prefer composition over giant prop matrices.
- Do not memoize by default; optimize measured problems.
- Use stable keys based on identity.
- Treat loading, error, empty and success states as part of the component contract.
