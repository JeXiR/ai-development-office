# Visual Regression Testing

Use stable scenarios:
- seeded deterministic data
- fixed viewport
- disabled/randomized animations
- stable timestamps
- stable fonts/assets

Capture:
- desktop
- tablet where relevant
- mobile

Do not treat every pixel difference as a product bug.
Review intended design changes explicitly.
