# Frontend Performance

Prioritize:
1. unnecessary JavaScript/client boundaries
2. oversized images/assets
3. duplicate dependencies
4. avoidable network waterfalls
5. expensive rerenders
6. layout shift
7. slow third-party scripts

Measure before complex optimization.
Prefer platform/framework features for image, font and code loading.
