# Template Source Selector

## Choose source type by problem

### New application shell
Prefer:
- existing internal starter
- official/framework starter
- purchased full template when it substantially reduces work

### One missing page
Prefer:
- existing app patterns
- page block/template source
- do not replace the app shell for one page

### One missing component
Prefer:
- current design system
- approved component library
- do not import a full template

### High-polish landing page
Allow:
- premium/free marketing blocks
- animated sources
- specialized effects

### Admin/dashboard
Prefer:
- stable application UI patterns
- accessible primitives
- tables/forms/charts over decorative effects

## Paid templates

Before use:
- record vendor and license
- check framework/version
- inspect dependencies
- choose visual-reference vs code-reuse mode
- avoid importing obsolete architecture wholesale
