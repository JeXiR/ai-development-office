# Responsive UI

Check:
- navigation collapse behavior
- table/list transformations
- chart minimum usable size
- form field stacking
- touch target size
- overflow
- sticky/fixed elements
- modal/sheet behavior
- typography line length
- safe-area handling for mobile/webview use

Do not hide essential functionality merely because the viewport is smaller.
