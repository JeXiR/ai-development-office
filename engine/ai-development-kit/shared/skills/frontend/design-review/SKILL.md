# Design Review

Review:
- clear primary action
- information hierarchy
- navigation clarity
- density
- form complexity
- table usability
- mobile behavior
- empty/error/loading states
- accessibility
- implementation complexity
- consistency with current product

Challenge decorative complexity that adds engineering cost without improving product clarity.
Prefer fewer coherent patterns over many flashy one-offs.
