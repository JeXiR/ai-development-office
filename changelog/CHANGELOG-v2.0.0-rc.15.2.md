# AI Development Office v2.0.0-rc.15.2 — Global Context Help

Added a global contextual-help layer with small information icons for buttons, checkboxes, selects, major headings and explicitly marked status/help elements.

Tooltips explain:
- what the element does,
- how it works,
- and what it can affect.

High-impact actions have dedicated explanations. Other controls receive safe type-aware help from their visible label.

Stable remains locked until final acceptance tests pass.
