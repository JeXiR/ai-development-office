# AI Development Office v1.1.11 — Office UI Localization

## Added
- Independent **Office UI Language** dropdown.
- UI languages: Türkçe, English, Deutsch, Русский.
- Navigation, top status bar, language settings and office theme settings are localized.
- UI language is persisted in browser localStorage.
- AI Response Language remains a separate project-level setting.
